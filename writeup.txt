Architectural Suggestions Beyond The Questions

1. True Embedding-based RAG (shared/kb.py):
   Instead of dumping articles into the prompt, index KB articles using vector embeddings. At query time, retrieve only top-1 or top-2 relevant articles. This scales cleanly to thousands of articles.

2. Semantic Response Caching:
   Hash order facts and customer intent. Identical ticket profiles can be served from cache without invoking the LLM.

3. Native Structured Outputs:
   Use JSON schema enforcement (e.g. response_format) instead of regex parsing, ensuring compact generation and preventing prompt injection.
